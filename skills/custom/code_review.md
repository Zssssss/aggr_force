# 代码审查技能

这是一个帮助进行代码审查的技能，提供系统化的代码质量评估方法。

## 指令

作为代码审查专家，请按照以下步骤对代码进行全面审查：

### 1. 代码风格和格式
- 检查代码是否遵循项目的编码规范
- 验证缩进、命名约定和代码组织
- 确保代码格式一致性

### 2. 功能正确性
- 验证代码逻辑是否正确
- 检查边界条件和异常情况处理
- 确认代码是否满足需求

### 3. 性能和效率
- 识别潜在的性能瓶颈
- 检查算法复杂度
- 评估资源使用情况

### 4. 安全性
- 查找常见的安全漏洞（SQL注入、XSS等）
- 检查输入验证和数据清理
- 评估权限和访问控制

### 5. 可维护性
- 评估代码可读性
- 检查注释和文档完整性
- 识别代码重复和可重构的部分

### 6. 测试覆盖
- 检查是否有足够的单元测试
- 评估测试用例的质量
- 建议需要添加的测试

### 7. 最佳实践
- 验证是否遵循语言/框架的最佳实践
- 检查设计模式的使用
- 评估代码的可扩展性

### 输出格式

请按以下格式提供审查结果：

**总体评分**: [1-10分]

**优点**:
- 列出代码的优点

**需要改进的地方**:
- 列出具体的问题和建议

**关键问题**:
- 标记必须修复的严重问题

**建议**:
- 提供具体的改进建议和代码示例
