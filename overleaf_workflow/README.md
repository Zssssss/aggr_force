# Overleaf自动化登录工作流

这个工作流使用Playwright实现Overleaf的自动化登录和项目访问。

## 功能特点

- 自动打开浏览器并导航到Overleaf登录页面
- 自动填充用户名和密码
- 支持人工完成验证（验证码、二次验证等）
- 自动查找并进入指定项目
- 自动打开指定的.tex文件进行编辑

## 使用方法

### 1. 安装依赖

```bash
cd overleaf_workflow
pip install -r requirements.txt
playwright install chromium
```

### 2. 运行脚本

```bash
python overleaf_login.py
```

### 3. 操作流程

脚本会自动执行以下步骤：

1. **启动浏览器** - 打开Chrome浏览器
2. **导航到登录页** - 访问Overleaf登录页面
3. **填充登录信息** - 自动填入邮箱和密码
4. **点击登录按钮** - 提交登录表单
5. **等待人工验证** - 如果出现验证码或二次验证，请手动完成
6. **查找项目** - 自动查找"resume-master-260105"项目
7. **打开文件** - 自动打开resume-zh_CN.tex文件

### 4. 注意事项

- 脚本会在需要人工验证时暂停，完成验证后按回车继续
- 浏览器会保持打开状态，方便您编辑文件
- 完成编辑后，按回车键关闭浏览器

## Hybrid模式说明

此脚本采用Hybrid模式（混合模式）：
- **自动化部分**: 浏览器启动、页面导航、表单填充、项目查找
- **人工部分**: 验证码识别、二次验证、文件编辑

这种模式结合了自动化的效率和人工的灵活性，特别适合需要人工验证的场景。

## 故障排除

### 问题1: 找不到登录输入框
- 检查Overleaf网站是否更新了页面结构
- 手动完成登录，脚本会在后续步骤继续

### 问题2: 找不到项目
- 确认项目名称是否正确
- 手动在浏览器中打开项目

### 问题3: Playwright未安装
```bash
playwright install chromium
```
